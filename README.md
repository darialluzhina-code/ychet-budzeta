# Семейный бюджет

Локальный веб-сервис учёта семейных доходов и расходов. Работает в браузере без сервера и регистрации: данные сохраняются в `localStorage`.

## Что внутри

- приветственная страница с кратким описанием;
- учёт доходов и расходов по категориям;
- лимит расходов на месяц и диаграмма категорий;
- редактирование, удаление и фильтр операций;
- экспорт месяца в CSV;
- светлая и тёмная тема.

## Как открыть

Самый простой способ — открыть `index.html` в браузере.

Либо поднять локальный сервер из корня проекта:

```bash
python3 -m http.server 8080
```

Затем перейти на [http://localhost:8080](http://localhost:8080).

- Главная: `index.html`
- Приложение учёта: `app.html`

Старый адрес `uchet_budjeta.html` перенаправляет в приложение.
